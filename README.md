# agents

Skills and useful things for agents.

## `skills/`

### `TMUX.md`

Teaches AI agents how to use tmux as a persistent, interactive terminal
environment through standard CLI commands, enabling them to operate long-running
processes, SSH sessions, REPLs, and interactive applications across tool calls.
Covers session management, sending input, inspecting terminal output, and
interacting with CLI software without requiring processes to terminate.
